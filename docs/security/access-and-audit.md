# Матрица доступа и аудит

## Доступ к данным сообщений
- Пользователь чата: чтение/отправка/редактирование своих сообщений в доступных чатах.
- Администратор платформы: не читает сообщения напрямую из БД; доступ только через регламентированные сервисные процедуры.
- Сервис backend: единственная точка расшифровки после проверки членства.

## События обязательного аудита
- `encrypt_message` (успех/ошибка, keyId, algorithmId, actorUserId, chatId).
- `decrypt_message` (успех/ошибка, keyId, algorithmId, actorUserId, chatId, messageId).
- Смена ключа и изменение ключевой конфигурации.
- Ошибки конфигурации TLS и отклоненные небезопасные подключения.

## Политика журналирования
- Журналы хранятся централизованно и неизменяемо.
- Срок хранения и доступ к журналам регулируется внутренней политикой ИБ.
- Доступ к журналам имеет только ограниченный перечень ролей.
