# Checklist готовности к ФСТЭК/ФСБ

## Криптоконтур
- [x] Сообщения шифруются перед записью в БД.
- [x] Расшифровка выполняется только на backend после проверки прав.
- [x] В ответах API/WebSocket клиент получает plaintext, в БД plaintext отсутствует.
- [x] Метаданные шифрования (version, algorithmId, keyId, iv, authTag) фиксируются в контракте.

## Транспорт
- [x] Введена политика `REQUIRE_TLS` для API и WebSocket.
- [x] В production backend не стартует без TLS-конфигурации.
- [x] Frontend запрещает insecure `VITE_API_URL` при HTTPS-контексте.

## Ключи и аудит
- [x] Есть primary key и поддержка набора предыдущих ключей для расшифровки.
- [x] Есть аудит encrypt/decrypt операций.
- [x] Есть базовый runtime-контроль параметров ротации ключей.

## Документация
- [x] Подготовлена модель угроз.
- [x] Подготовлен регламент управления ключами.
- [x] Подготовлены правила доступа и аудит-событий.

## Для формальной аттестации (следующий этап)
- [ ] Подключить сертифицированное СКЗИ вместо dev-криптопровайдера.
- [ ] Утвердить пакет организационно-распорядительных документов.
- [ ] Провести формальные процедуры оценки соответствия с профильным подрядчиком.
